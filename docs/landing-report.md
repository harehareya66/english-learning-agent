# 智能体接入产品 · 落地方案报告

> 说明：本文件为飞书《英语智能体接入产品 · 落地方案报告》的本地存档。
> 产品原型截图见本地 `screenshots/` 目录（01-home ~ 07-chat，7 张）。

## 一、产品定位

**一句话定位**：一款「本地优先 + AI 增强」的智能体英语学习产品：以词根词源法学习词汇，以艾宾浩斯算法巩固记忆，以 AI 大模型提供个性化讲解，实现"简单功能零成本、复杂需求交给 AI"。

**目标用户与核心价值**：

| 维度 | 目标用户 | 核心价值 |
|------|---------|---------|
| K12 同步学习 | 中小学生及家长 | 词根词源联想记忆，告别死记硬背 |
| 大学应试备考 | 四六级 / 考研备考生 | 艾宾浩斯科学复习，动态测评检验掌握度 |
| 职场英语 | 有场景口语需求的职场人 | 场景化口语模板 + AI 自由对话陪练 |

**产品形态**：从传统"聊天助手"进化为「功能中心」形态：侧边栏提供学习中心、背单词、单词库、复习、测评、场景口语、AI 对话七大功能入口，本地能力独立成页、直连本地数据，AI 对话作为唯一调用大模型的入口并通过知识注入连接本地词库。

## 二、功能现状统计

**功能模块清单**：

| 模块 | 核心功能 | 实现方式 | Token 成本 |
|------|---------|---------|-----------|
| 学习中心 | 统计概览、掌握度进度、每日目标打卡、快速入口 | 本地 SQLite 统计 + localStorage 打卡 | 0 |
| 背单词 | 主动回忆式背诵、发音 | 本地队列 + 艾宾浩斯调度 + TTS | 0 |
| 单词库 | 词根分组浏览、搜索、词根词源拆解、加入学习计划、发音 | 本地 SQLite 词库 + 确定性拆解 | 0 |
| 复习 | 今日待复习（单词+错题）、中英分离、自评反馈 | 本地艾宾浩斯算法 | 0 |
| 测评 | 固定题+动态题、答案后端存储、答错解析、错题归档 | 本地题库 + 内存答案映射 | 0 |
| 场景口语 | 3 个场景、浏览/跟读双模式 | 本地场景模板 | 0 |
| AI 对话 | DeepSeek 自由对话、本地词库知识注入、多会话管理 | 大模型 API + 检索注入 | 按 token |
| 错题本 | 测评答错自动归档、回流复习队列、自评巩固 | 本地 SQLite | 0 |
| 设置 | API Key / 模型配置、自定义 Agent、主题切换 | 本地配置文件 | 0 |

**本地能力与 AI 能力分工**：

| 能力 | 实现 | 成本 |
|------|------|------|
| 查词 / 词根拆解 | 本地词库 + 确定性拆解逻辑 | 0 token |
| 复习调度 | 本地艾宾浩斯算法 | 0 token |
| 测评 / 错题 | 本地题库与答案映射 | 0 token |
| 场景口语 | 本地场景模板 | 0 token |
| 自由对话 / 个性化讲解 | DeepSeek API | 按 token 计费 |
| AI 知识注入 | 提取消息单词 → 检索本地词库 → 注入上下文 | 极少量 |

**关键数据指标**：

| 指标 | 数值 |
|------|------|
| 词库规模 | 30 个单词，覆盖 13 个词根词族 |
| 口语场景 | 3 个（机场出行 / 餐厅点餐 / 商务会议） |
| 测评题量 | 4 道固定题 + 基于已学词的动态题（词根 / 词义 / 词族三种题型） |
| 首屏体积 | 约 10KB JS（路由懒加载拆分，2.6MB 优化后） |
| 技术栈 | React + Vite + TDesign + Node.js + Express + better-sqlite3 + DeepSeek |

## 三、智能体落地架构

**总体架构**：产品采用三层混合架构：前端 React 单页应用；后端 Express 服务承担意图分流与本地能力执行；数据层使用本地 SQLite（词库、记忆、会话全量本地存储），AI 层接入 DeepSeek 大模型。核心设计原则是"能本地解决的不调模型"。

**意图分流机制**：用户消息进入后端后，由意图分类器识别五种本地意图（查词、复习、口语、错题、测评）与 AI 对话意图：

1. 关键词匹配：复习 / 口语 / 错题 / 测评等明确意图词直接路由到本地能力。
2. 纯英文单词：识别为查词，本地返回词根词源拆解。
3. 自然语言含英文单词且命中本地词库：识别为查词，本地讲解。
4. 其余消息：路由到 AI 对话（无 API Key 时给出本地功能引导）。

**知识注入机制**：AI 对话前，后端提取消息中的英文单词，逐一检索本地词库；命中的单词将其词根拆解与词族信息注入 AI 系统提示词，约束大模型基于本地词库的准确词根词源讲解。

**记忆系统**：本地维护 word_memory 记忆表，采用艾宾浩斯遗忘曲线调度：首次学习进入队列，自评"记得"则复习间隔逐级递增、掌握度提升；自评"忘记"则间隔重置、掌握度回落。测评答错的题自动归档错题本并立即回流复习队列。

## 四、工作流程

- **意图分流流程**：用户输入 → 意图分类 → 本地能力分支（0 token）或 AI 分支（对话 + 知识注入）→ 文本或交互卡片返回前端。
- **学习闭环流程**：学词 → 写入记忆库 → 到期进入复习队列 → 复习自评驱动艾宾浩斯 → 测评检验 → 答错归档错题本 → 错题回流复习 → 掌握。
- **记忆调度流程**：首次学习记录初始状态 → 到期提醒复习 → 用户自评 → 更新掌握度与下次复习时间 → 间隔递增直至熟练掌握。

## 五、用户体验流程

- **首次使用**：进入学习中心看到全局统计 → 点"开始背单词"进入主动回忆背诵，或浏览单词库学习词根词源 → 单词库点"学习"加入记忆计划。
- **每日学习路径**：背单词 → 复习到期词 → 测评检验 → 打卡记录。
- **完整学习闭环**：背词学新词 → 复习巩固 → 测评检验 → 答错进错题本 → 错题回流复习 → 掌握度提升 → 数据回写统计与打卡。

## 七、结论

本产品以"本地优先 + AI 增强"的混合智能体架构落地，将高频、确定性的学习能力沉淀为本地零成本能力，将低频、开放性的对话讲解交给大模型，并通过意图分流与知识注入实现两种能力的安全衔接。当前已完成功能闭环与体验打磨，具备作为独立学习产品使用的基础。
