# 零基础用户视角 · 背单词体验优化清单（2026-08-15）

> 用视觉脚本实跑背单词页三种题型（听音选词 / 看词选义 / 拼写），假设自己是「什么都不会、第一次用」的零基础用户，记录的真实感受。

## 核心发现：产品定位错位

这个产品的核心能力——**词根词源记忆法、四六级/考研词库、IPA 音标、发音评分**——明显面向「有英语基础的大学生备考者」，**不是零基础用户**。「什么都不会的用户」用它处处碰壁，不是 bug，是定位。

## 零基础用户的具体感受（实跑记录）

三种题型的实际渲染，零基础用户看到的是：

| 题型   | 实际显示                                                     | 零基础用户感受                   |
| ---- | -------------------------------------------------------- | ------------------------- |
| 看词选义 | passage + `/pæsʌdʒ/` + 中文选项（日子/职业/段落、通道/部分、地段）           | 音标看不懂；中文选项勉强能选            |
| 听音选词 | passage + `/pæsʌdʒ/` + 英文选项（encourage/passage/face/poor） | 选项全英文不认识；不知道 passage 怎么读  |
| 拼写   | passage + `/pæsʌdʒ/` + 「段落、通道」+ 输入框                      | **要我拼出 7 字母英文？字母都不熟，做不到** |

## 问题清单（按严重度）

| # | 严重度 | 问题                                                      | 优化建议                                           |
| - | --- | ------------------------------------------------------- | ---------------------------------------------- |
| 1 | 🔴  | **拼写题对零基础是降维打击**：刚学就要求拼写 7 字母不规则英文词，无任何字母提示             | 拼写题加「字母提示」（如 `p______` 显示首字母+字母数），或零基础模式下去掉拼写题 |
| 2 | 🔴  | **音标 `/pæsʌdʒ/` 看不懂**：全题型都显示 IPA 音标，零基础看是「天书」，反而焦虑      | 提供「自然拼读 / 谐音」提示（如 passage≈「拍塞举」），或隐藏音标         |
| 3 | 🟡  | **听音选词选项全英文无中文**：encourage/face/poor 零基础不认识             | 选项加中文释义（encourage 鼓励 / face 脸 / poor 穷）        |
| 4 | 🟡  | **发音评测门槛高**：跟读评分对发音不准的零基础打击信心                           | 零基础模式降级为「跟读回放对比」，不强制评分                         |
| 5 | 🟡  | **答错后词根词源「天书」**：「词根 port（搬运）」是陌生概念，无科普                  | 零基础模式隐藏词根词源，或首次科普「什么是词根」                       |
| 6 | 🟢  | **缺入门引导（onboarding）**：打开就是「第 1/20 个 · 拼写」，不知从哪开始、没有难度选择 | 加首次引导 + 难度选择                                   |

## 建议方向（二选一）

### 方向 A · 覆盖零基础：加「难度分层」

- 首次进入让用户选「零基础 / 有基础 / 备考冲刺」
- 零基础模式：隐藏音标（改自然拼读）、拼写题加字母提示、听音选项加中文、隐藏词根词源、题型只保留「看词选义」
- 有基础/备考：保持现状（词根词源 + 全题型）

### 方向 B · 坚持备考定位：明确目标用户

- 产品定位写清楚「面向四六级/考研备考者」，不追求零基础
- 但仍可做小优化：题型按难度渐进（先选义 → 再拼写/听音/发音）、拼写题加提示、听音选项加中文

## 我的建议

**方向 B 为主 + 吸收 A 的低成本项**：这个产品明确是备考工具（词库就是四六级/考研），不建议为了零基础大改。但「拼写题加字母提示」「听音选项加中文」「题型按难度渐进」这几项**对所有用户都有价值**（哪怕备考者也受益），值得做。
